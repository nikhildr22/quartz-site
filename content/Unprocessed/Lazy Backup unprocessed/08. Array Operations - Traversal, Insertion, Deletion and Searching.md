## Traversal:
use loop to traverse array indices.

Traversal = visiting all elements of the array.

## Insertion
inserting a element at a particular index.
This is costly operation, after insertion, few elements should be moved to the next position.

Best case: O(1) --> last postion
Worst case: O(n) --> first position

case 2: if the order of elements does not matter --> constant time

What if the insertion size increases than the total capacity?
we need to create a new array with sufficient capacity and copy all elements into new bigger array and then insert.

## Deletion
best case : O(1)
worst case: O(n)

case 2: if the order of elements does not matter --> constant time.

## Searching
Linear search --> when array is not sorted
Binary search --> when array is sorted

#todo OOPS notes

Array - collection of elements accessible by index.

When we allocate the memory for an array, we'll get the contigous memory.
since the memory is contigous, resizing in the same memory location is not possible. for resizing we need to copy and keep in another array.


Accessing array elements can be done with time complexity of O(1).

get and set are easy, but insertion and deletion are costlier operations in array.
